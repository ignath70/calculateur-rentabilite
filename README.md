# Calculateur de rentabilité — immeuble à revenus (Québec)

Outil d'analyse pour dégrossir un immeuble à revenus avant de faire une offre :
cashflow par porte, ratio de couverture de la dette, taux de capitalisation,
rendement sur mise de fonds, points de bascule pour la négociation, test de
résistance et liste de vérifications avant offre.

**Une seule page, aucune dépendance.** Tout le code tient dans `index.html` :
pas de serveur, pas de compte, aucune donnée envoyée nulle part. Les chiffres
saisis restent dans le navigateur de la personne qui l'utilise.

## Utilisation

- En ligne : https://ignath70.github.io/calculateur-rentabilite/
- Hors ligne : téléchargez `index.html` et ouvrez-le par double-clic. Il
  fonctionne sans connexion.

## Particularités

- Paiement hypothécaire calculé avec la composition semestrielle canadienne
- Droits de mutation du Québec calculés automatiquement, corrigeables à la main
- Prêt achat-rénovation : les travaux peuvent être inclus dans le financement
- Sauvegarde et reprise par fichier ou par copier-coller

## Avertissement

Outil de dégrossissage, à des fins d'information seulement. Ne constitue pas un
avis professionnel. Validez vos chiffres avec un courtier hypothécaire, un
comptable et un inspecteur en bâtiment avant toute transaction.
